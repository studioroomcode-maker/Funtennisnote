# 재미있는 테니스 노트 EP.01 — 노란 테니스공 78초 쇼츠 제작 패키지 · EVIDENCE V3.1

## 제작 결론

- 최종 권장 길이: **78초**
- 매크로 컷: **18개**, 컷당 3.8~5.0초
- 컷 내부 멀티샷: **2~3개**, 실질 화면 변화 **약 43회**
- 권장 평균 샷 유지시간: **1.4~2.0초**
- 정보 리셋 숫자: **625/50 → 2년 → 1972 → 1986**
- 핵심 편집 리듬: 역설 후킹 → 과거의 색 선택 → TV에서 생긴 문제 → 시인성 연구 → 1972년 허용 → 전통의 저항 → 1986년 전환 → 최종 반전
- 기존 7컷·43초 버전과 별개인 **고밀도 v2 기획안**이며 기존 에셋과 매니페스트는 덮어쓰지 않는다.
- 생성 영상 자체는 완전 무음으로 만들고, 한국어 내레이션은 후반 작업에서 별도 합성한다.

## 포맷 분석을 반영한 재설계

‘신비한 건축사전’형 고밀도 설명 쇼츠의 핵심은 특정 색감 하나가 아니라 **시각 체계를 계속 바꾸면서도 하나의 질문을 놓치지 않는 구조**다. 이번 버전은 다음 원칙으로 재설계한다.

1. 첫 1.2초 안에 “선수용 색”이라는 상식을 “TV 시청자용 색”으로 뒤집는다.
2. 같은 구도를 오래 유지하지 않는다. 매크로 펠트 → 역사 디오라마 → 코트 비교 → CRT 단면 → 실험실 → 규칙서 → 연대표 → 현대 화면으로 시각 체계를 순환한다.
3. 7~9초마다 수치나 고유명사를 크게 제시한다. 단, 화면 문구는 짧은 영어 전문용어만 쓴다.
4. 빨간 지시선은 장식이 아니라 ‘지금 봐야 할 것’을 0.2초 먼저 가리키는 시선 유도 장치로 사용한다.
5. 테도리는 기본적으로 등장시키지 않는다. 캐릭터의 기능이 분명한 후킹, 난관 비트, 반전 선언, 결말의 4개 컷에서만 선택적으로 사용하고 나머지 14개 컷은 공·코트·CRT·실험 구조만으로 진행한다.
6. 생성 컷은 18개지만 컷 내부에 2~3개 샷을 넣어 실제 시각 변화는 약 43회로 만든다.
7. 역사 장면은 실제 기록 영상처럼 위장하지 않고 일관된 교육용 미니어처 시뮬레이션으로 표현한다.
8. 핵심 주장은 사실 → 원리 → 화면 근거로 설계하되, 한 컷에는 근거를 하나만 넣는다.
9. 기술 그래픽은 0.8~1.5초, 영어 전문용어 2개, 숫자 2개를 넘기지 않는다. 기술 컷 두 개 뒤에는 반드시 전체 모습이나 결과 컷을 둔다.

## 공식 자료 팩트 체크

- 과거 테니스공은 코트 배경색에 따라 검은색 또는 흰색을 사용했다.
- ITF 자료는 연구 결과 노란 공이 텔레비전 시청자에게 더 잘 보였다고 설명한다. 본 패키지는 이를 밝은 배경에서의 휘도 대비 손실과 컬러 방송에서의 색상 대비 추가로 시각화하되, 임의의 향상률은 만들지 않는다.
- ITF 공식 연혁은 **2년간의 시험 뒤 1972년 노란 공 사용이 허용**됐다고 설명한다.
- 윔블던은 전통적인 흰 공을 계속 사용했고, 공식 자료상 **108년간 흰 공을 쓴 뒤 1986년 노란 공으로 전환**했다.
- 1970년대 방송 환경 그래픽은 ITU가 정리한 525/60·625/50, 2:1 인터레이스 규격을 사용한다. 이는 시대적 맥락이며 노란 공 도입의 단독 원인으로 단정하지 않는다.
- 따라서 “노란 공이 선수 경기력 때문에 도입됐다”, “1972년에 흰 공이 금지됐다”, “모든 대회가 동시에 바뀌었다”라고 표현하지 않는다.

- 나레이션은 결론과 핵심 원리 하나만 읽는다.

- 7번 컷은 규격, 8번 컷은 휘도 대비, 11~13번 컷은 해결 원리와 시험을 담당한다.

## 최종 내레이션 대본

평범한 테니스공 하나를 먼저 보겠습니다. 지금은 노랗지만 원래부터 이 색은 아니었습니다. 초기 테니스는 코트 배경에 따라 검은 공과 흰 공을 골랐습니다. 현장에서는 공과 바닥의 대비만 확보하면 충분했습니다. 공의 색은 코트가 정하는 선택이었습니다.

문제는 경기가 아날로그 텔레비전 안으로 들어오며 시작됐습니다. 당시 화면은 한 장면을 두 번에 나눠 그렸습니다. 작은 흰 공이 밝은 코트 선과 겹치면 휘도 대비가 급격히 줄었습니다. 그렇다고 공을 키우거나 경기 속도를 늦출 수는 없었습니다. 문제는 여기서 완전히 꼬입니다.

답은 화면에 색상 대비를 하나 더 남기는 것이었습니다. ITF는 2년 동안 노란 공 사용을 실험했습니다. 옵틱 옐로는 색 차이를 더해 공을 배경에서 분리했습니다. 1972년, ITF 규칙은 노란 공을 공식 선택지로 허용했습니다.

그런데 전통은 기술보다 훨씬 천천히 움직였습니다. 윔블던은 그 뒤로도 흰 공을 오랫동안 고수했습니다. 방송이 먼저 공의 색을 바꿨고 전통은 뒤늦게 따라왔습니다. 익숙한 노란 공에는 화면을 위한 대비 설계가 숨어 있습니다.

## 내레이션 녹음·편집 기준

- 목소리: 한국어가 자연스러운 신뢰감 있는 30~40대 남성 시사·교양 아나운서 톤. 영어 기반 한국어 음성은 사용하지 않는다.
- 속도: 평상시보다 **1.10~1.15배 빠른 자연 발화**, 숫자는 또렷하게 읽는다.
- 문장 사이 무음: **70~110ms**, 문단 사이 무음: **140~180ms**. 자동으로 긴 쉼을 삽입하지 않는다.
- 의도적 큰 호흡은 10번 컷의 난관 비트 뒤와 18번 컷의 최종 회수 직전, 총 2회만 둔다.
- 전체 길이를 맞추려고 오디오 타임 스트레치를 하지 말고 대본을 압축하거나 재녹음한다.
- 권장 감정 곡선: 0~12초 호기심 70% → 12~40초 압박 82% → 40~60초 역전 86% → 60~72초 전통과 기술의 대비 78% → 72~78초 확신 68%.

## 공통 앵커 원문

### 한국어

공통 앵커 — 세로 9:16, 8K, 시네마틱 포토리얼 3D 과학·방송 시뮬레이션, 테니스공 색의 역사를 설명하는 초정밀 미니어처 디오라마. 테도리(Tedori)는 기본적으로 등장시키지 않으며 컷 고유 지시가 명시한 경우에만 assets/tedori_character_sheet_final.png를 강한 캐릭터 레퍼런스로 사용한다. 등장할 때는 광학 노란색 구형 테니스공 몸체, 정확한 두 개의 흰색 곡선 심, 대칭 검은 타원 눈, 아주 작은 미소, 짧은 팔과 발, 진한 외곽선, 절제된 프리미엄 셀 셰이딩을 정확히 유지하고, 지시가 없는 컷에 테도리나 다른 캐릭터를 임의로 추가하지 않는다. 실제 테니스공은 미세한 펠트 섬유, 고무 코어, 두 조각 펠트 셸과 하나로 이어지는 곡선 심을 정확히 표현하며 축구공·야구공 무늬나 추가 심을 금지한다. 핵심 피사체인 테니스공, 코트, 텔레비전과 실험 장치는 선명한 풀컬러로, 불필요한 배경·군중·보조 소품은 저채도 무채색 회청색으로 처리한다. 고정 색상 체계는 광학 노랑, 딥 테니스 네이비, 웜 화이트, 페일 스카이블루, 다크 올리브와 코럴 포인트이며, 역사 장면만 따뜻한 세피아·크림 톤을 더한다. 필요하면 테니스공, CRT 텔레비전, 카메라와 실험 장치를 정밀 단면도·분해도·엑스레이 컷어웨이로 열어 시인성과 영상 전달 과정을 보여준다. 지정된 짧은 영어 전문용어만 허용하며 테크니컬 레드(#FF2A2A) 지시선, 치수 화살표, 추적 궤적과 비교 프레임이 움직이는 대상에 고정된다. 각 컷의 핵심 주장에는 원리·규격·비교 중 하나만 증거 레이어로 붙이고 0.8~1.5초 안에 읽히게 한다. 한 컷의 영어 전문용어와 숫자는 각각 최대 2개이며 출처 없는 비율·소수점·성능 향상치는 만들지 않는다. 그 밖의 글자, 문장, 자막, 브랜드 로고, 대회 문장, 워터마크와 UI는 금지한다. 끊임없는 공 궤적과 방송 시뮬레이션, 안정적인 비모핑 오브젝트, 빠르고 매끄러운 MULTI-CUT 및 MULTI-SHOT 정보 흐름. 상세 단면에서 동적 DOLLY-OUT으로 하이앵글 아이소메트릭 전체 규모를 드러내고 즉시 다른 구획으로 DOLLY-IN 또는 ZOOM-IN하며, 컷 고유 카메라 앵글과 샷 사이즈를 우선 적용한다. 현실적인 중력, 공의 탄성, 펠트 반응, CRT 주사선과 색 번짐, 시네마틱 볼류메트릭 조명, 선명한 재질, 고밀도지만 즉시 읽히는 구성. 모든 역사 장면은 교육용 시각 재구성이며 특정 인물·브랜드·방송사의 실제 기록 영상처럼 위장하지 않는다. 나레이션 없음, 성우 목소리 없음, 대사 없음, 배경음악 없음, 효과음 없음, 생성 오디오 없음.
