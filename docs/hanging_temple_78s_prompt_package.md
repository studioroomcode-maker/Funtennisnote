# 현공사 78초 쇼츠 — 내레이션·컷 설계·한영 영상 프롬프트

## 제작 결론

- 최종 권장 길이: 78초(사용자 요청 범위 1분~1분 30초)
- 매크로 컷: 18개, 컷당 4.0~4.5초
- 컷 내부 멀티샷: 2~3개, 실질 화면 변화 36~45회
- 권장 평균 샷 유지시간: 1.5~2.3초
- 핵심 편집 리듬: 역설 후킹 → 높이 체감 → 과거 문제 → 실패 가설 → 횡목 공법 → 2차 위기 → 결구/하중 반전 → 기둥 셀프 문답 → 지진 검증 → 카타르시스
- 생성 영상 자체에는 나레이션·성우·배경음악·생성 오디오가 없으며, 한국어 내레이션은 후반 작업에서 별도로 합성한다.

## 실제 고조회수 콘텐츠 분석

2026-08-25 확인 기준 신비한 건축사전은 약 66.8만 구독자, 333개 영상 규모였고, 외부 채널 통계는 쇼츠 평균 길이를 약 1분 32초로 집계한다. 인기순 상위에는 “한강이 강이 아니라 호수인 이유”(약 543만), “서울 한복판 억새밭, 사실은 쓰레기 9,200만 톤 위에 떠 있습니다”(약 470만), “경복궁 마당은 평평해 보이지만 사실 평평하지 않습니다”(약 370만)처럼 익숙한 대상을 모순 문장으로 뒤집는 제목이 집중되어 있다.

직접 확인한 대표 영상의 초반은 약 2~3초마다 항공 풀샷 → 지도 → 수중 단면 → 정투상 단면으로 시각 체계를 바꾸고, 붉은 치수선과 수치 라벨을 피사체에 고정해 설명한다. 대본은 보통 여섯 개 안팎의 비교적 긴 의미 단위로 “현재의 이상함 → 과거의 문제 → 첫 해결 → 새 문제 → 반전 해결 → 현재 결과”를 완결한다. 이번 설계는 같은 정보 밀도를 유지하면서도, 18개 매크로 컷 안에 36개 이상의 내부 샷을 배치해 더 빠른 텐션을 만든다.

## 팩트 체크 메모

- 건립 시점은 북위 491년으로 전해지며 1,500년 이상 된 사찰이다.
- 높이는 기준점과 시대별 하상 퇴적·정비 때문에 자료마다 약 58~90m로 다르다. 영상에서는 널리 알려진 “약 75m”를 사용한다.
- 공식 관광·건축 자료는 약 50cm 지름의 횡목 27개, 쐐기식 고정, 장부 결구와 암반 하중 전달을 설명한다.
- 아래 수직 기둥은 전부 가짜가 아니다. 평소 주 하중은 횡목과 암반이 담당하지만 방문객이 많을 때 일부 기둥도 보조 지지하며, 시각적으로 위태로운 인상을 만드는 장식 기능도 겸한다.
- 공식 자료는 1989년 규모 6.1 지진에도 현공사가 버텼다고 설명한다.

## 최종 나레이션 대본

이 사찰은 아래 기둥이 거의 받치지 않는데도 1,500년째 서 있습니다. 중국 산시성 현공사, 절벽 약 75미터 위에 매달려 있거든요. 491년 무렵 장인들 앞엔 평평한 땅이 한 뼘도 없었죠. 바닥부터 기둥을 세우면 절벽만 한 구조물이 필요했을 겁니다. 결국 땅을 버리고 절벽 자체를 기초로 삼은 셈입니다.

암벽에 구멍을 뚫고 지름 약 50센티미터 횡목 27개를 박았습니다. 목재 끝을 쐐기처럼 깎아 깊숙이 밀어 넣었거든요. 힘이 걸릴수록 바위 안에서 더 단단히 물리는 구조였죠. 그 위에 복도와 전각을 올리자 새로운 문제가 생긴 겁니다. 바깥으로 튀어나온 횡목은 휘고, 빠지고, 비에 썩을 수 있는 셈입니다.

장인들은 전각과 복도, 난간을 장부 결구로 한 덩어리처럼 묶었습니다. 하중을 한 점에 몰지 않고 절벽 전체로 흩어 보냈거든요. 그럼 아래 가느다란 기둥은 전부 가짜일까요? 그렇진 않습니다. 사람이 몰릴 때 일부 하중을 보조하죠. 다만 기본 하중은 횡목을 타고 암반으로 들어가는 겁니다.

절벽의 돌출부는 비와 강한 햇빛까지 막아줬습니다. 실제로 1989년 규모 6.1 지진 뒤에도 현공사는 버텼죠. 현공사는 절벽 위에 선 건물이 아니라, 절벽 속에 박힌 건물인 셈입니다.
