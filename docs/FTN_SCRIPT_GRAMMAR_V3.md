# 재미있는 테니스 노트 · SCRIPT DNA V3

## 목표

90초 안에 익숙한 테니스 대상을 낯설게 보여주고, 두 겹의 난관과 직관을 뒤집는 해결을 거쳐 한 문장으로 기억되게 만듭니다. 건축 다큐형 숏츠의 기능적 리듬은 참고하지만 문구와 유행어는 복제하지 않습니다.

## 4파트 고정 구조

### 1. 지시와 전복 · 0~12초 · 2~3문장

- 브랜드 시작 문장: `평범한 {대상} 하나를 먼저 보겠습니다.`
- 즉시 전복: `{대상}은 {상식}처럼 보입니다. 실제로는 {반대 사실}입니다.`
- 정보 설명보다 대상 지시와 지식 공백을 우선합니다.
- 큰 숫자는 꼭 필요할 때 한 번만 사용합니다.

### 2. 두 겹의 난관 · 12~40초 · 5~6문장

- 난관 A: 중력·회전·충격·마찰·시간·규칙 중 하나를 적대자로 세웁니다.
- 난관 B: 뻔한 해결책을 쓰지 못하는 이유를 붙여 딜레마로 만듭니다.
- 브랜드 비트 마커: `문제는 여기서 완전히 꼬입니다.`
- 이 문장 뒤부터 해결이 시작된다는 리듬 신호로 사용합니다.

### 3. 역전 해결 · 40~72초 · 6~7문장

- 브랜드 반전 선언: `답은 정반대에 있었습니다.`
- 해결은 `더 강하게`보다 `반대로`, `더하기`보다 `빼기`, `고정`보다 `움직이기`를 우선합니다.
- 해결 본체 1개와 부가 이득 1~2개를 제시합니다.
- 전문용어는 한 번만 쓰고 바로 평범한 말로 바꿉니다.
- 해결 숫자는 꼭 필요할 때 한 번만 허용합니다.

### 4. 압축 요약 · 72~90초 · 4문장

- 문제 한 문장, 해결 한 문장, 결과 한 문장으로 압축합니다.
- 브랜드 마침 문장: `익숙한 {대상}에는 이런 계산이 숨어 있습니다.`
- 결말 감정은 감탄형·경고형·안도형을 에피소드마다 교대합니다.
- 도입과 같은 앵글을 회수하되 이제 대상이 다르게 보이게 만듭니다.

## 문장 규칙

- 16~18문장, 한 문장 25~35자 권장, 한 문장 = 한 컷입니다.
- 종결은 `-습니다/-입니다`로 통일합니다.
- `-거든요`, `-셈입니다`, 수사형 `-죠`, 청자 질문을 사용하지 않습니다.
- `여러분`, `구독자`, `보이시나요`처럼 청자를 부르지 않습니다.
- 접속사 `그렇다고`는 난관 B, `답은`은 반전 선언에서만 사용합니다.
- 주어는 공·라켓·줄·코트·규칙입니다. 사물이 버티고, 밀고, 숨기고, 되돌립니다.
- 숫자는 훅 1개와 해결 1개가 최대입니다. 나머지는 일상 언어로 설명합니다.
- 자막은 짧은 영어 전문어 또는 숫자만 사용하고, 핵심 설명은 픽토그램과 붉은 방향선으로 처리합니다.

## 금지 패턴

- 같은 부연 어미를 연속 사용하지 않습니다: `거든요 / 셈입니다 / 그렇죠`.
- 질문을 던지고 답하는 셀프 문답을 기본 장치로 사용하지 않습니다.
- 난관을 한 번만 말하고 바로 해결하지 않습니다.
- 해결을 `더 튼튼하게 만들었습니다`처럼 예상 가능한 방식으로 끝내지 않습니다.
- 한 문장에 원인·과정·결과를 모두 넣지 않습니다.
- 제목이나 대본에서 원본 채널의 시그니처 문구를 그대로 사용하지 않습니다.

## 제목 공식

`익숙한 대상 + 위협/반전 동사 + 이유`

- 좋은 예: `너무 강한 회전 때문에 금지된 라켓`
- 좋은 예: `새 공 통을 열면 압력이 먼저 빠져나오는 이유`
- 피할 예: `테니스 라켓에 관한 흥미로운 사실 5가지`

## 자동 검수 조건

- [ ] 4파트가 타임코드로 구분됩니다.
- [ ] 16~18문장이고 문장 수와 컷 수가 같습니다.
- [ ] 난관 A와 난관 B가 모두 있습니다.
- [ ] 반전 해결이 직관과 반대 방향입니다.
- [ ] `거든요`, `셈입니다`, `그렇죠`, `여러분`이 0회입니다.
- [ ] 전문용어가 반복되지 않습니다.
- [ ] 도입 앵글이 마지막 컷에서 회수됩니다.
